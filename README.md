Part 1(a)
Team Member Responsilbities:
We as a group collaborated together on developing, testing, and debugging the MIPS Fibonacci assembly program.

How to Run the Fibonacci(n) MIPS Program
1. Open the MARS MIPS Simulator, then our part (a) file.
2. In the .data section, find the line n: .word 5 and change 5 to any nonnegative number.
3. Save the file then click run to assemble the program.
4. Then click run, go, to execute the program.
5. Once executed, go to the execute tab and check the Data Segment to see the value stored in result. This value represents the nth Fibonacci number.

Part 1(b)
Team Member Responsibilities:
We collaborated together on developing, testing, and debugging the MIPS IsOdd(m) assembly program. We worked as a group to make sure the program correctly determines whether a given number is odd or even using division by repeated subtraction.

How to Run the IsOdd(m) MIPS Program
1. Open the MARS MIPS Simulator and open our part (b) file.
2. In the .data section, find the line m: .word 5 and change 5 to any nonnegative number you want to test.
3. Save the file, then click run and assemble to assemble the program.
4. Then click run, then go to execute the program.
5. Once executed, go to the execute tab and check the data segment to see the value stored in result.
6. If the result is 1, the number is odd. If the result is 0, the number is even.

Part 1(c)
Team Member Responsibilties:
All three of us collaborated together on developing, testing, and debugging the final MIPS IsFibonacciOdd(n) assembly program. We worked together to combine our Fibonacci and odd-number detection programs, making sure the program correctly calculates the nth Fibonacci number and determines whether it is odd or even.

How to run the  IsFibonacciOdd(n) MIPS Program
1. Open the MARS MIPS Simulator and open our Part (c) file.
2. In the .data section, find the line n: .word 5 and change 5 to any nonnegative integer you want to test.
3. Save file, then click run then assemble to assemble the program.
4. Click Run then go to execute the program.
5. The program first calculates the nth Fibonacci number, then checks if the number is odd or even using division by repeated subtraction.
6. Once executed, go to the execute tab and check the Data Segment to see the value stored in result.
7. If the result is 1, the nth Fibonacci number is odd. If the result is 0, the nth Fibonacci number is even.
