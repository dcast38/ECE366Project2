How to Run the Fibonacci(n) MIPS Program
1. Open the MARS MIPS Simulator, then our file
2. In the .data section, find the line n: .word 5 and change 5 to any nonnegative number.
3. Save the file then click run to assemble the program.
4. Then click run, go, to execute the program.
5. Once executed, go to the execute tab and check the Data Segment to see the value stored in result. This value represents the nth Fibonacci number.
